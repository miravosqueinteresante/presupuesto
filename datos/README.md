# Dataset abierto — PGN 2027 (Paraguay)

Proyecto de Presupuesto General de la Nación 2027. Datos públicos del MEF,
procesados y con citas de fuente+página para trazabilidad.

- `pgn2027.json` — dataset estructurado (ver `SCHEMA.md`).
- `pgn2027-cifras.csv` — tabla maestra de cifras.
- `salud-programas.csv` — detalle por programa del Ministerio de Salud.

Uso libre con atribución y cita de fuente. Generado 2026-09. Total informado
Gs. 166.322.078.980.116 (D01 p.1). Nota: proyecto de ley aún no sancionado.
