# Esquema de datos — PGN 2027 (data/open)

JSON `pgn2027.json`: meta · macro · economia · instituciones_2027 · areas ·
variaciones · estructura · salud (total_gs, total_ley_gs, gs_2026, diccionario,
programas[]) · fuentes[]. Ver README.

CSV `pgn2027-cifras.csv` = tabla maestra (concepto;valor_gs;valor_usd;fuente_id;pagina;dimension).
CSV `salud-programas.csv` = desglose por programa del MSPyBS (codigo;programa;monto_g;pct_total;fuente;pagina).
Dimensiones: D1 macro · D2 institucional · D3 clasificación · D4 programas · D5 comparativa 2026.
